# Design-and-Implementation-of-a-Human-Resources-Management-System-for-FCAH-PT
Ojo Samuel Ayomide (NDCOM/24/617), Ilori Temilade Praise (NDCOM/24/615) Oyelekan Oswald Folahan (NDCOM/DPT/24/074) Moshood Fawas Akorede (NDCOM/24/671) A web-based Human Resources Management System (HRMS) designed to improve staff record management, automate human resource processes, and enhance administrative efficiency. The system provides a centralized platform for managing employee information, organizing personnel records, and improving data storage, retrieval, accuracy, and security within the institution.
